# Gestor de tareas - Angular
Aplicación desarrollada en Angular para la gestión de tareas pendientes y completadas. 

# Funcionalidades
- Visualización de tareas en una tabla dinamica.
- Creación de nuevas tareas mediante formulario reactivo.
- Cambio de estado de tareas utilizando checkbox.
- Actualización visual del estado de cada tarea.
- Validación de datos en formulario.
- Diseño utilizando Angular Material.

# Tecnologías utilizadas
- Angular.
- TypeScript.
- Angular Material.
- Reactive Forms.
- CSS grid.

# Mock de datos

La aplicación utiliza un archivo db.json como mock de datos para simular el almacenamiento y gestión de tareas sin necesidad de un backend real o base de datos.

# Instalación

Clonar el repositorio:
  git clone URL_DEL_REPOSITORIO

Instalar dependencias:
  npm install

Ejecutar el proyecto:
  ng serve -o
